# 命名書オーダーサイト「ちいさな手Saki」設計書

- 日付: 2026-08-22
- 状態: ユーザー承認済み（2026-08-22）／同日追記: 紙の種類・生年月日の有無・実写真・プレビュー刷新（ユーザー指示）
- STORESストアURL: https://chiisanatesaki.stores.jp

## 1. 目的と概要

手書き（毛筆）の命名書を受注販売するウェブサイト。納品は物理（執筆して郵送）。

- 紹介・プレビュー用の**静的サイト**（GitHub Pages・無料）＋ **決済はSTORES**（フリープラン・アカウント開設済み）のハイブリッド構成
- 固定費0円。売上発生時のみSTORES決済手数料（約5%）
- 特定商取引法の表記はSTORESの住所非公開設定を利用し、個人住所を出さない

## 2. 全体アーキテクチャ

```
自作サイト（GitHub Pages）              STORES（決済）
┌────────────────────┐        ┌────────────────────────┐
│ 紹介・ギャラリー（仮画像）      │        │ 商品2種＋包装オプション商品      │
│ 命名書プレビュー＆注文ビルダー   │  →     │ 購入者氏名・郵便番号・住所・      │
│ 注文テキスト自動生成＆コピー    │ リンク   │ 電話番号はSTORESが標準収集     │
│ ご注文の流れ・FAQ           │        │ 命名内容は備考欄（必須設定）      │
└────────────────────┘        └────────────────────────┘
                                            ↓
                                      執筆 → 郵送（手作業）
```

- 購入者の個人情報（氏名・郵便番号・住所・電話番号）は**STORESの購入画面のみ**が扱う。自作サイトは個人情報を一切送信・保存しない（プレビュー入力はブラウザ内で完結）
- 命名内容（名前・ふりがな・生年月日）の受け渡しは**A案**：サイトのプレビューで入力 → 注文テキストを自動生成 → 購入者がコピーしてSTORES備考欄に貼り付け
- 備考欄の記入漏れがあった場合はSTORESのメッセージ機能で確認する運用

### ヒーローの筆書きイントロ（2026-08-22追記・ユーザー承認済み）

### 生年月日の有無（2026-08-22追記・ユーザー確定）

- 注文ビルダーに「命名書に生年月日を入れる」チェックを設ける（既定オン）
- オフ時: 日付入力を無効化し、プレビューから消し、注文テキストは「【生年月日】記載しない」

### 身長・体重の有無（2026-08-22追記・ユーザー確定）

- 「命名書に身長・体重を入れる」チェックを設ける（既定オフ）。オンで身長(cm)・体重(g)の入力欄が現れる
- プレビューでは生年月日の隣に小さく縦書きで「身長 49.5cm」「体重 3,250g」の形で表示（入力がある項目のみ）
- 注文テキストは「【身長・体重】49.5cm／3,250g」、オフ時は「【身長・体重】記載しない」。価格への影響なし

### プレビューの構図（2026-08-22刷新）

実物の見本写真に合わせ、「名前を大きく＋ふりがな由来のローマ字サイン（筆記体）」の構図とする。生年月日・身長・体重はサインの下に「2026.05.21 48cm 3200g」の形式で横書き（Caveat・入力があるもののみ。2026-08-23変更）。紙の種類・キャンバス・フレームの選択はプレビューの背景・縁に反映する（模様あり1は白オーバーレイで明度補正）。

## 5. サイト構成（1ページ・スマホ最優先）

1. **ヒーロー**: サイト名「ちいさな手Saki」＋命名書写真（仮画像）＋キャッチコピー
2. **こだわり**: 一枚ずつ手書き・毛筆で執筆すること
3. **商品ラインナップ**: ハガキ／A4／キャンバスの3枚看板＋オプション一覧表（2026-08-22に3商品構成へ変更）
3.5. **書き手のこと**（2026-08-22追加）: 執筆者の想い（本人提供の文面そのまま・書道10年＋保育士の経歴）と後ろ姿の写真（assets/photo-writer.jpg・EXIF除去済み・顔なしで匿名性維持）。見本帖と注文ビルダーの間に配置
4. **命名書プレビュー＆注文ビルダー**（目玉機能）
   - 入力: 名前（漢字）／ふりがな／生年月日（日付選択）
   - 選択: サイズ／素材／フレーム／包装 → 合計金額をリアルタイム表示
   - 表示: 縦書き・毛筆風フォントで命名書イメージを描画。生年月日は和暦（令和）変換。「実物は手書きのためイメージです」と注記
   - 「注文内容をコピー」ボタン → 整形テキストをクリップボードへ → 該当するSTORES商品ページへのリンクを表示
   - 注文テキスト書式:
     ```
     【お名前】太郎（たろう）
     【生年月日】令和8年8月1日
     【サイズ】A4　【素材】紙　【フレーム】あり
     【プレゼント包装】あり
     ※包装ありの場合「プレゼント包装(300円)も一緒にカートへお入れください」を付記
     ```
5. **ご注文の流れ**: ①プレビューで確認 → ②注文内容をコピー → ③STORESで購入（備考欄に貼り付け）→ ④執筆・発送

7. **フッター**: 特商法表記（STORESページへリンク）、コピーライト

## 6. 技術仕様

- HTML／CSS／JS（vanilla）の静的1ページ＋assets。ビルドツールなし
- フォント: Google Fonts「Yuji Syuku」（毛筆風・プレビュー用）＋「Shippori Mincho」等（本文用明朝）
- プレビューの縦書き: CSS `writing-mode: vertical-rl`
- コピー: `navigator.clipboard`（非対応時はテキスト表示して手動コピーにフォールバック）
- 和暦変換: JS実装。令和のみ対応（2019-05-01以降チェック）
- レスポンシブ: モバイルファースト
- 公開: GitHub Pages（pushはユーザー操作。Claudeはpush認証不可のため）
- デザイントーン: 和・上品・清潔感。実装時にデザイン系スキルを適用
- 写真: 当面プレースホルダ仮画像。後日ユーザー撮影の実物写真に差し替え

## 7. エラーハンドリング・エッジケース

- 長い名前: フォントサイズ自動調整（文字数に応じて縮小）
- 環境依存文字・旧字体: プレビューで表示できない場合がある旨を注記し、備考欄での補足を案内
- 生年月日が令和以前・未来日: 警告表示（注文自体は妨げない）
- clipboard API非対応: 注文テキストを画面表示して手動コピー
- 備考欄の記入漏れ: STORESメッセージで確認する運用ルール（FAQにも明記）

## 8. 動作確認項目（実装後に手順書として提示）
